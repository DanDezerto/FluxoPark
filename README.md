# FluxoPark

## Sobre o projeto

O FluxoPark é uma aplicação para ajudar motoristas a encontrar estacionamentos
próximos ao destino e planejar onde deixar o veículo. O usuário pode consultar
informações como distância, preço, horário de funcionamento e disponibilidade
de vagas, comparar estabelecimentos e solicitar uma vaga para o período
desejado. A plataforma também oferece recursos de gestão para estacionamentos
parceiros. Os pagamentos disponíveis nesta versão são demonstrativos.

## Tecnologias utilizadas

- **Interface:** HTML, CSS, JavaScript e React 18
- **Desenvolvimento e build:** Vite
- **Estilização:** Tailwind CSS e arquivos CSS próprios
- **Dados e API local:** Node.js e json-server
- **Consultas e formulários:** TanStack Query, React Hook Form e Zod
- **Mapas e busca geográfica:** Google Maps Platform
